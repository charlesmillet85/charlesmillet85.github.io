# charlesmillet85.github.io

The site that shows all of Charles Millet's apps. Plain HTML, CSS and JavaScript, hosted on GitHub Pages at https://charlesmillet85.github.io/.

## Change something

1. Edit `data/apps.mjs`. It holds every app: name, text, icon, colours, media, links.
2. Run `node build.mjs` (needs Node 18 or later). It rewrites `index.html`, `404.html` and `apps/<app>/index.html`.
3. Commit and push. GitHub Pages publishes within a minute.

To add an app, copy one entry in `data/apps.mjs`, put its icon in `assets/icons/` and its pictures or videos in `assets/media/`, and run the build.
When an app goes live, set `status: "live"` and add its `storeUrl`.

## Files

| Path | What it is |
|---|---|
| `data/apps.mjs` | All the content |
| `build.mjs` | Turns the content into pages |
| `assets/site.css` | All the styles |
| `assets/site.js` | All the interactions (scroll effects, galleries, film player, filters) |
| `assets/icons/`, `assets/media/` | Icons, pictures and compressed videos |
| `index.html`, `404.html`, `apps/` | Generated by `build.mjs`: don't edit by hand |

## Existing support and privacy pages

The apps' support and privacy pages stay in their own repositories (`hello-duo`, `spatial-home`, `folioplayerplus`, `relief`, `spatial-posts`), so the URLs already given to App Store Connect keep working. App pages here live under `/apps/` so they never clash with those paths.

## Preview locally
